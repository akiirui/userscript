# Use My Fonts

Replace some fonts to custom font.

- `Mono`: [Cascadia Code][CascadiaCode]
- `Sans-EN`: [Roboto][Roboto]
- `Sans-JP`: [Source Han Sans][SourceHanSans]
- `Sans-KR`: [Source Han Sans K][SourceHanSans]
- `Sans-SC`: [Source Han Sans SC][SourceHanSans]
- `Sans-TC`: [Source Han Sans TC][SourceHanSans]

[CascadiaCode]: https://github.com/microsoft/cascadia-code
[Roboto]: https://github.com/googlefonts/roboto-3-classic/releases
[SourceHanSans]: https://github.com/adobe-fonts/source-han-sans/releases
